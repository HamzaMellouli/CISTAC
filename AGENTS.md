# Antigravity Workspace Rules — Front-End Design System

This repository enforces the **Doodle (Hand Drawn) Design System** for all front-end and dynamic agent implementations across the `ai4brain` platform. Whenever generating, editing, or refactoring front-end code (React, HTML, CSS, Tailwind, Three.js, Canvas), you **MUST** strictly adhere to the following guidelines:

---

## 1. Design Philosophy: "Playful Precision & Tactile Growth"
* **Doodle & Sketch Aesthetics:** Warm paper canvas (`#FFF5EE`), navy pen ink strokes (`#263D5B`), terracotta brand highlights (`#E86A33`), and tactile offset shadows (`3px 3px 0 #263D5B`).
* **Non-Clinical & Growth Mindset:** Avoid any clinical, diagnostic, or deficit labels. Emphasize neuroplasticity, curiosity, and calibration.
* **Low-Friction Focus (Trial Mode):** During active cognitive testing blocks, distractions dissolve cleanly while preserving the micro progress bar and responsive tactile feedback.
* **Friendly Brian Mascot:** Incorporate Brian the Brain Mascot for encouragement, milestones, and debriefing.

---

## 2. Mandatory Color Tokens & Theming
All styles must reference the design tokens defined in `frontend/src/styles/tokens.css`:

* **Canvas (Warm Paper):** `#FFF5EE` / `hsl(25, 100%, 97%)` (Global background with 24px subtle dot grid)
* **Surface (Whiteboard / Card):** `#FFFFFF` (Cards, dialogs, widgets)
* **Surface Raised (Pill / Tint):** `#FDF0E7` (Tokens, interactive badges)
* **Ink (Navy Charcoal):** `#111827` (Primary typography)
* **Ink Muted (Slate):** `#4B5E78` (Secondary metadata, instructions)
* **Border Strong (Pen Stroke):** `#263D5B` (Mandatory 2px or 2.5px solid borders)
* **Brand (Terracotta Orange):** `#E86A33` (CTA buttons, key highlights, active vectors)
* **Brand Hover:** `#D55823`
* **Reward (Sunshine Gold):** `#FFC83D` (Celebration states, high mastery)

### Dark Theme (`[data-theme="dark"]` / Night Lab):
* **Canvas:** `#131B2E`
* **Surface:** `#1E293B`
* **Ink:** `#FFFFFF`
* **Border Strong & Brand:** `#FF8C5A`
* **Shadow:** `3px 3px 0 #FF8C5A`

---

## 3. Typography & Numerical Scannability
* **Display / Headings:** `Delius Swash Caps` or `Delius`, cursive.
* **Body / Reading:** `Delius`, cursive, or `Lexend` fallback.
* **Telemetry & Scores:** `JetBrains Mono`.
* **Mandatory Jitter Prevention:** All numerical telemetry (reaction time in ms, standard deviations, scoring distributions) **MUST** use `font-variant-numeric: tabular-nums` (class `.tabular-nums` / `.font-mono-tabular`).

---

## 4. Components & Buttons
* **Tactile Cards (`.tactile-card`, `.neuro-card`):** `#FFFFFF`, `2px solid #263D5B`, `border-radius: 12px`, `box-shadow: 3px 3px 0 #263D5B`.
* **Tactile Buttons (`.tactile-btn`, `.neuro-button-primary`):** Min height `44px`, `border: 2px solid #263D5B`, `box-shadow: 3px 3px 0 #263D5B`, `border-radius: 8px`. On hover: `transform: translate(-1px, -1px); box-shadow: 4px 4px 0 #263D5B`. On active: `transform: translate(2px, 2px); box-shadow: 1px 1px 0 #263D5B`.
* **Progress Bar:** 4px bar with `--color-brand` (`#E86A33`) on `--color-border` track.

---

## 5. Agent-Generated UX Sandboxes
All HTML/CSS/Canvas/SVG execution payloads generated by `UXSandboxRenderer` (`backend/app/tools/ux_sandbox_renderer.py`) MUST render using the Doodle Design System tokens, Delius/JetBrains Mono fonts, and tactile components.
